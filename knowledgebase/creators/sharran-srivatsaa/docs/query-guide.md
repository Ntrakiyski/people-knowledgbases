# Answer questions from the wiki

1. Read [the root index](../index.md) and [coverage status](../status.md).
2. Follow the concepts or entities index to the relevant page.
3. Read its `Sources` section and follow the video summary to its raw transcript.
4. Verify the claim in context and cite the video with the timestamp.
5. If coverage is missing, state that the knowledge base cannot answer the question yet.

For example, a question about Sharran's investing framework requires transcript
evidence. The presence of an investing video title in the catalog is insufficient.
